Button

A pressable action. Primary for the one thing the view is for, secondary beside it, tertiary for the quiet way out, and danger for a destructive confirmation.

Variants

Signal orange is deliberately not a variant: it is reserved for consent and legal actions.

Follows the page theme and corners 4 variants 
import { Button } from '@snapshot-ui/react';

// One primary per view; the others step down.
<Button>Save changes</Button>
<Button variant="secondary">Preview</Button>
<Button variant="tertiary">Discard</Button>
<Button variant="danger">Delete site</Button>

States

Pending keeps the width and focus, and announces itself. Disabled is the only grey.

Usage

Install both packages and import the stylesheet once.

import '@snapshot-ui/core/styles.css';
import { Button } from '@snapshot-ui/react';

export function SaveBar({ isSaving }: { isSaving: boolean }) {
  return (
    <Button type="submit" isPending={isSaving} pendingLabel="Saving">
      Save changes
    </Button>
  );
}

Props

Every React Aria Button prop is accepted. These are the ones Snapshot UI adds or shapes.

variant
"primary" | "secondary" | "tertiary" | "danger"

Visual emphasis.

Default: "primary"

isPending
boolean

Shows a spinner, ignores presses, stays focusable and announces the change.

Default: false

pendingLabel
string

Accessible name of the spinner while pending.

Default: "Loading"

isDisabled
boolean

Removes the button from interaction.

Default: false

onPress
(event: PressEvent) => void

Fires on click, Enter, Space and touch, with no ghost clicks.

Accessibility

A native button element, with React Aria handling press across input types.

Space EnterActivates the button.
TabMoves focus to it, and the 2px ink ring appears outside the pill.
PendingStill focusable. The spinner's name joins the button's, so screen readers hear "Save changes, Saving".

Design rules

One primary per view. Pair it with a secondary or a tertiary.

Labels are verbs, in sentence case: "Save changes".

Never orange. Signal orange belongs to consent and legal actions.
