Add MultiSelect: choose several values from a list, built on React Aria's ComboBox in multiple mode. The chosen values are bone tags in a frame that wears the field's edges and grows a row at a time; the list stays open after each choice and the input empties; a tag is removed by its button, by Backspace or Delete, or by Backspace twice from an empty input, which first focuses the last tag. `value` is `readonly Key[]` and `onChange` receives `Key[]`, never `selectedKey`; `name` submits one value per chosen key; a tag shows its option's text value, so an option whose label is not a string needs `textValue`. With `inputValue` controlled too, empty it in `onChange`. `labels` adds `selected` and `remove` to ComboBox's. One Escape closes the list and empties the input; Tab and Shift+Tab close it and move on, and never change the value. While the list is open React Aria hides the tags from assistive technology, and a press on a remove button still removes its tag. `isReadOnly` keeps the tags focusable, with no remove buttons and no removal. Without a visible label the tags are named "Selected" and the field's `aria-label` or `aria-labelledby`. Without a visible label the placeholder is slate. React Aria announces in its own strings, which have no Persian, its tag description "Press Delete to remove tag." too. New exports: `MultiSelect`, `MultiSelectBaseProps`, `MultiSelectProps` and `MultiSelectLabels`. `multi-select.css` in `styles.css`.
