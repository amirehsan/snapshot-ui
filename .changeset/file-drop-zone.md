Add FileDropZone, PageDropZone and FileButton: three ways in for files, with one check. `acceptedFileTypes` (MIME types, wildcards and extensions, as an `<input accept>` takes them; list an extension beside each MIME type, since systems disagree on types, and a file with no type is checked by its extension), `maxFileSize`, `allowsMultiple` and `maxFiles` are checked the same on a drop, a paste and a choice, and `onFiles(accepted, rejected)` gives you the files that passed and each refusal with its reason (`'type'`, `'size'`, `'count'`, `'empty'`); a partial drop adds what passes. FileDropZone is a field, a group named by its label, with one tab stop, its "Choose files" button, which also takes a paste; a click anywhere on its box opens the picker too. It says its refusals once, politely, in your words through `labels.rejected(count, formatted, rejected)` or `errorMessage`, by default "1 file was not added: it is too large". PageDropZone draws an overlay only while files are dragged over the page, in the closest AppShell or the body, clear of the rail, and takes a paste of files anywhere outside a text field; it is for the pointer, so pair it with a FileButton beside the page's title. A page has one page zone. FileButton is React Aria's FileTrigger around the library's Button, and choosing the same file again fires again. `capture` (`'environment'` or `'user'`) opens a phone's camera; on iOS and Android it makes the button the camera's only, so give it a FileButton of its own beside the one that chooses files. While a zone is mounted, a file dropped beside it, on a form's text field included, does nothing rather than open in the tab. A dropped folder is refused as `'type'`, carried as an empty `File` with its name, and never read. The library never reads or sends a file: check every file again on your server. Exports `FileDropZone`, `PageDropZone`, `FileButton` and the types `FileDropZoneProps`, `FileDropZoneBaseProps`, `FileDropZoneLabels`, `PageDropZoneProps`, `FileButtonProps`, `FileAcceptance`, `FileRejection` and `FileRejectionReason`. `file-drop-zone.css` in `styles.css`.
