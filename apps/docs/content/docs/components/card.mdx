## Header and body

The header holds a title and a note and is ruled off from the body. The title is the card's heading. A long word breaks anywhere in a card, and an element that must not break, such as a code sample, can set `overflow-wrap: normal`.

## Nesting

A card placed in another card, directly or in its body, steps its corner down to the surface radius and takes an outline, because a card on a card has no tone step to set it apart.

## Usage

Card is static. It renders on the server and ships no JavaScript. For a card that folds, use [Collapsible card](/docs/components/collapsible-card). Choose the element with `as` and the heading level with `level`, so the card fits the page's outline.

```tsx
import { Card, CardBody, CardHeader, CardNote, CardTitle } from '@snapshot-ui/react';

export function Notifications() {
  return (
    <Card as="section" aria-labelledby="notifications-title">
      <CardHeader>
        <CardTitle id="notifications-title" level={2}>
          Notifications
        </CardTitle>
        <CardNote>Where we reach you, and how often.</CardNote>
      </CardHeader>
      <CardBody>...</CardBody>
    </Card>
  );
}
```

## Accessibility

A card is a div unless `as` says otherwise. A `section` with a name, from `aria-labelledby` or `aria-label`, is a region landmark, and without a name it is not announced. An `article` is not a landmark, named or not.

The header is a div rather than a header element. A header outside sectioning content is the page's banner, so two cards at page level would add two. The title renders the heading level you choose and looks the same at every level.

A card is not interactive: to make one lead somewhere, put a link in its title, and never nest buttons or links in a card that is clickable.
