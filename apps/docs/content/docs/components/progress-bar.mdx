## Determinate

`value` runs from `minValue` to `maxValue`, 0 to 100 unless you say otherwise, and is clamped to them. The label sits at the start of the head and the value at its end, over an 8px track whose ink fill moves to each new value over 200ms. The value is a whole percentage by default; `valueLabel` puts it in your own words, such as "1.2 of 4 MB", when a percentage says too little.

## Indeterminate

`isIndeterminate` is for work of unknown length, such as reading a document: a segment slides across the track and starts again, and the bar has no value. It shows no value text unless you set `showValueLabel` with a `valueLabel` of your own. When the reader asks for reduced motion the segment slows, and never stops, since a still segment would read as an amount.

## Usage

ProgressBar is static. It renders in a server component and ships no client JavaScript. It is never a live region, since a value that changes many times a second would be read out each time: say what matters once in your own status, as the upload tray does, and a screen reader user who reaches the bar hears its current value. The default value text is written in ASCII digits, so a Persian page passes `valueLabel` in its own digits, as it passes every other string. A meter measures against a limit; a progress bar measures work getting done.

```tsx
import { ProgressBar } from '@snapshot-ui/react';

<ProgressBar label="Uploading invoice.pdf" value={45} />;

// In a row that names the file already: no head, named by aria-label.
<ProgressBar aria-label="Uploading invoice.pdf" value={45} showValueLabel={false} />;

// Work of unknown length.
<ProgressBar label="Reading receipt.jpg" isIndeterminate />;
```

## Accessibility

The track is a `role="progressbar"`, named by the label, `aria-label` or `aria-labelledby`, and with none of them by its value text, so it is never unnamed.

- While determinate it carries `aria-valuemin`, `aria-valuemax`, `aria-valuenow` and `aria-valuetext`, which is `valueLabel` or the percentage. The visible value text is hidden, since the bar reads it.
- While indeterminate it carries none of the four, which is how the role says the amount is unknown. A `valueLabel` shown on purpose describes the track instead.
- It is not live: it announces nothing as it moves.
- It takes no focus and has no keys.
- In forced colors the track keeps an outline and the fill is drawn in the reader's text color.
