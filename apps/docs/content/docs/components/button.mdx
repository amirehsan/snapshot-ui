## Usage

Pass `isPending` while work runs. The button stays focusable, ignores presses and does not submit its form. `pendingLabel` names the spinner and joins the button's name while it waits, so this one reads "Save changes Saving".

```tsx
import { Button } from '@snapshot-ui/react';

export function SaveBar({ isSaving }: { isSaving: boolean }) {
  return (
    <Button type="submit" isPending={isSaving} pendingLabel="Saving">
      Save changes
    </Button>
  );
}
```
