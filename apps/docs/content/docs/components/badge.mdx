## Tones

Neutral is the base. Info, success, warning and error only change the color. Error means invalid or failed, success means success, and warning means a state that needs a look soon and is not a failure, such as Watch, Behind, Needs review or Out of date. Name the state in the label: none of them is ever decoration, in sample content included, and warning is never a stand-in for the attention cue. Clay and signal orange are never tones: they mean unsaved work and consent.

## Usage

A static `span` with no React Aria, so it works in a server component without `'use client'`.

```tsx
import { Badge } from '@snapshot-ui/react';

export function Row() {
  return (
    <p>
      Release notes <Badge tone="info">New</Badge>
    </p>
  );
}
```

## Accessibility

Color is never the only signal. The label says what the badge means, and the tone repeats it. A badge is not announced when it changes: if a count updates while the page is open, put it in a live region.
