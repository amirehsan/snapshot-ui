## Tones

Neutral is the base. The other tones only change the color, and the label always names the state.

- Error: invalid or failed.
- Success: success.
- Warning: needs a look soon but is not a failure, such as Watch, Behind, Needs review or Out of date.

No tone is ever decoration, even in sample content. Warning never stands in for the attention cue, the light orange that marks a change, such as a changed field's border. Clay and signal orange are never tones: they mean unsaved work and consent.

## Usage

A static `span` with no React Aria, so it works in a server component without `'use client'`.

```tsx
import { Badge } from '@snapshot-ui/react';

export function Row() {
  return (
    <p>
      Release notes <Badge tone="info">New</Badge>
    </p>
  );
}
```

## Accessibility

Color is never the only signal. The label says what the badge means, and the tone repeats it. A badge is not announced when it changes, so put a count that updates in a live region.

</Section>
