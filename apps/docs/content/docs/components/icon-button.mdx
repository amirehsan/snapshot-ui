## Variants

Ghost has no fill and no edge. Outline draws a 1px ink edge, for a button that has to show where it is.

## States

Hover and press wash the circle with a little ink, in dark as well. Disabled turns the icon taupe and ignores presses.

## As a link

Give it an `href` and it renders an anchor with the same classes and the same need for a name. Use the link form for an icon that goes somewhere, and the button form for one that does something.

## Usage

The child is the icon. It is hidden from assistive technology, so the name comes from `aria-label` or `aria-labelledby`, and the types require one of them.

```tsx
import { IconButton } from '@snapshot-ui/react';
import { Settings } from 'lucide-react';

export function SettingsButton({ onOpen }: { onOpen: () => void }) {
  return (
    <IconButton aria-label="Open settings" onPress={onOpen}>
      <Settings />
    </IconButton>
  );
}
```

## Accessibility

A native button element, or an anchor when there is an `href`, with React Aria handling press across mouse, touch and keyboard. It is 40px square, which meets the touch target on its own.
