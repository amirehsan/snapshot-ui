## Anatomy

A tile shows an overline label in slate capitals, the value as a small numeral, a change line with an arrow and your sentence, and a caption for the period. Only the label and the value are required. The tile uses the Card's surface, and its padding follows density.

## The change line

The line is slate by default. Set `tone` to `gain` only for money that arrived, and to `warning` only for a state that needs a look. Direction never sets the color: "Down 12%" is good for spending and bad for income. The sentence carries the meaning, and the arrow repeats it.

## A trend

Pass a small drawing, up to 96 by 32, in `trend`. The [Sparkline](/docs/charts/sparkline) is made for it. It sits at the end of the value's row, and moves under the caption when the tile has less than 18rem of content. It is hidden from assistive technology unless it names itself, since the text already says the change.

## A gauge as the trend

A 32px [Gauge](/docs/components/gauge) fits the trend's slot, for a share rather than a change over time: credit used of a limit, a goal saved. A gauge is a meter that names itself, so it is read in the tile; give it an `aria-label` that says what share it is, and its value text beside it.

## As a link

`href` makes the whole tile one link, routed through `RouterProvider` as [Routing](/docs/routing) sets up. Its name is everything it shows, in order. Put nothing focusable inside it: a link cannot hold a link or a button, and the console warns when one does.

</Section>

<Section>

## In a row

A tile is a size container, so it takes its width from its column, never from its content. Lay tiles in a grid such as `repeat(auto-fit, minmax(16rem, 1fr))`, not in a row that sizes them by content. Cap the minimum at the row's width, as below, so a column narrower than 16rem holds one tile and nothing scrolls sideways.

```css
.tiles {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(16rem, 100%), 1fr));
  gap: var(--spacing-peer);
}
```

</Section>

## Usage

Pass every figure as a formatted string. The library formats no number or date, so the server's HTML is final in any locale. A tile without `href` renders in a server component with no client JavaScript. A linked tile is a client part.

```tsx
import { StatTile } from '@snapshot-ui/react';

<StatTile
  label="Spending"
  value="$1,284.50"
  change={{ direction: 'up', label: 'Up 12% from last month' }}
  caption="Across all accounts"
  href="/spending"
/>;
```

</Section>

## Props

A plain StatTile accepts every attribute of an HTML element. A linked one is React Aria's `Link`, which forwards only `id`, `data-*`, `lang`, `dir`, `hidden`, `style`, `aria-label`, `aria-labelledby`, `aria-describedby`, `aria-details`, `aria-current` and the event handlers. Others, such as `title` or `role`, apply only to the plain tile.

## Accessibility

The tile is read as its text, in order: the label, the value, the change and the caption. A linked tile is one link named by that text. The arrow is hidden, since the sentence says the change. `level` makes the label a heading, so the tile joins the page outline.
