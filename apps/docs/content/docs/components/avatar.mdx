## Sizes and shapes

`sm`, `md` and `lg` are 24, 32 and 40px, with initials at 12, 14 and 16px. The small one is bolder, because 12px is the floor for short uppercase text.

- `circle`: a person. It takes the pill radius.
- `square`: a merchant's or a bank's logo, so it reads as a tile and not a face. It takes the micro radius.

Both follow the shape axis. A 1px ring edges the box, so a white logo on a white card keeps its edge.

## Initials

With no image, or while it loads, or if it fails, the avatar shows the first character of the first two words of `name`: Grace Hopper is GH and Northwind is N. Pass `initials` to set them yourself, such as WF for a bank. A failed image is removed, leaving the initials under it, so the box never moves and no broken-image icon shows.

The fallback is one neutral look for everyone: bone with ink initials. There is no color per name, because the name already identifies the person, and such a palette would need colors the system does not have.

## Beside a name

When the name is in the text beside the avatar, pass `isDecorative`. The avatar is then hidden from assistive technology, so the row is read once.

## Usage

`name` is required. It gives the initials and, unless the avatar is decorative, the accessible name. Serve the image from your own origin. Avatar is a client component for one piece of state: whether the image failed. The image stays hidden until it is known to have loaded, so a page shows the initials until it hydrates.

```tsx
import { Avatar } from '@snapshot-ui/react';

<Avatar name="Ada Lovelace" src="/people/ada.png" size="lg" />
<Avatar name="Northwind" src="/logos/northwind.svg" shape="square" />
```

## Accessibility

An avatar is an image named by `name`. The initials and the image inside it are hidden, so it is read once by its name, never as letters. With `isDecorative`, the whole avatar is hidden. It takes no focus and has no keys.
