## Heading

`level` picks the element and `size` picks the look. The size follows the level unless you set it, so a card title can be an h2 in the card-title step.

<Preview name="heading-sizes" />

Headings scale down on small screens:

- Display: 48px under 1024px, 40px under 768px.
- Section: 28px under 768px.

## Numerals

Use a numeral size for a figure that is the point of a tile. Both use tabular digits.

- `size="numeral"`: a hero amount, 56px, dropping to 44px under 768px so "$12,345.67" fits a 320px screen.
- `size="numeral-sm"`: a tile beside others, 32px.

A numeral never wraps, because a broken number reads wrong. Keep it to one figure. Two `numeral-sm` tiles cannot share a row at 320px, so let the row wrap (`flex-wrap`), as the example does. Put the sign and unit in the string, since nothing is formatted here. A numeral reads left to right in every direction, so "+$1,980.00" keeps its order on a right-to-left page.

## Eyebrow

The small capitalised label above a heading, with the accent dot. The dot hangs into the gutter, so the label lines up with the heading below. With no gutter, `inset` keeps the dot inside the label's box. An Eyebrow is an inline-level flex box, so it sits on a line like text, and two can share a line. Space it from the heading with a grid or flex gap, as the examples do, not with margins.

## Usage

None of the three needs a client boundary: they render plain elements and import no React Aria.

```tsx
import { Eyebrow, Heading, Text } from '@snapshot-ui/react';

export function SectionIntro() {
  return (
    <header>
      <Eyebrow>Foundations</Eyebrow>
      <Heading level={2}>Everything a dashboard asks for.</Heading>
      <Text tone="muted">Type and color come from tokens.</Text>
    </header>
  );
}
```

## Accessibility

A Heading is a real h1 to h4 element, so assistive technology reads the page outline whatever size it is drawn in. An Eyebrow is a label, never a heading, so it stays out of the outline. Muted text is slate, which clears 4.5:1 on every surface.

A numeral is read as the digits it shows, so the sign and unit belong in the text. A change line beside it says the direction in a word, never in color alone.
