## Basic

An icon, a title, one line and one action, centered in a column. The title says what is missing in the reader's words, and the line says what to do about it. The action is the one thing that fixes it.

## In a card

An empty state is a card's empty body, or a table's. Set `headingLevel` to the step under the heading that holds it: under a card title at level 3, the empty state's title is level 4.

## In a data table

[Data table](/docs/components/data-table)'s `emptyState` takes one, drawn across every column of its empty body. Its title says what the table is missing, such as "No transactions this month", and its action is the one that brings rows back, such as clearing the filters.

</Section>

## Usage

Empty state is static. It renders in a server component and ships no client JavaScript. Pass a Lucide icon element, which the empty state draws at 24px in slate and hides from assistive technology. Give it one action at most, such as a `Button` that clears the filters or imports the first rows.

```tsx
import { Button, EmptyState } from '@snapshot-ui/react';
import { Receipt } from 'lucide-react';

export function NoTransactions() {
  return (
    <EmptyState
      icon={<Receipt />}
      title="No transactions this month"
      description="Transactions you add or import show here."
      action={<Button variant="secondary">Import transactions</Button>}
    />
  );
}
```

## Accessibility

The title is a heading at `headingLevel`, a level 3 by default, so the empty state fits the page's outline: pick the step under the heading that holds it. The icon is hidden from assistive technology, since the title says what it shows. The action is your own control and is named by its own text. The text is slate and ink, which pass AA on the page, a card and a floating panel.
