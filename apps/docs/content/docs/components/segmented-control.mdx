## Basic

Pass a label, and the options as children, each with its own `value`. The chosen option is the ink pill. Use it for a few short options that are all worth seeing at once. For more, or for options that need explaining, use a list.

## States

The track's edge carries the state, as in every field.

- Changed: a light signal orange edge and a clay chip beside the label.
- Invalid: the error edge and an error line. Invalid outranks changed, so the chip steps aside.
- Disabled: recessed, with the chosen option kept in view as a quiet taupe pill.
- One disabled option: set `isDisabled` on its item, and the rest stay open.
- Compact: `size="sm"` draws 32px options in a 40px track, still hit at 40px.

## Stacking

The options sit all in one row or all in a column, never a mix. When the row does not fit, the control stacks one 40px option per row, and returns to a row when the room comes back.

The control compares its row with its own width, so give it a column to fill, as you would a text field.

- Content-sized: a control sized to its content, such as in a flex row or a centered grid, has nothing to compare with and never stacks.
- Before hydration: stacking is decided in the browser, so before hydration or with scripts off, a row that does not fit overflows its root.
- Spacing: add spacing outside the control, as a margin or a wrapper. Horizontal padding on the root through `className` makes the measured room wider than the track's.

## Usage

Every value works controlled and uncontrolled, and a control with a `name` submits the chosen `value` in a plain form. `onChange` receives the value. A `value` of `null` is a controlled control with nothing chosen.

```tsx
import { useState } from 'react';
import { SegmentedControl, SegmentedControlItem } from '@snapshot-ui/react';

export function Appearance({ saved }: { saved: string }) {
  const [mode, setMode] = useState(saved);
  return (
    <SegmentedControl
      label="Appearance"
      name="appearance"
      value={mode}
      onChange={setMode}
      isChanged={mode !== saved}
    >
      <SegmentedControlItem value="light">Light</SegmentedControlItem>
      <SegmentedControlItem value="dark">Dark</SegmentedControlItem>
      <SegmentedControlItem value="system">System</SegmentedControlItem>
    </SegmentedControl>
  );
}
```

Without a visible label, name the control with `aria-label` or `aria-labelledby`, such as a toolbar switch named by what it sits beside. The types require one of the three. Every option takes `children`. An icon-only option passes the icon there and adds an `aria-label`.

## Accessibility

A native radio group: each option is a radio, the label names the group, and React Aria handles the wiring. While the control is changed and valid, a screen reader reads the Changed chip after the hint. An invalid control reads its error line alone. The group is one tab stop, and focus lands on the chosen option.

<Keys rows={[['Tab', 'Moves focus into the control, onto the chosen option, or the first when nothing is chosen.'], ['Right Down', 'Chooses the next option, and wraps from the last to the first.'], ['Left Up', 'Chooses the previous option, and wraps from the first to the last.'], ['Space', 'Chooses the focused option.']]} />

- Focus ring: 2px, outside an unchosen option. On the chosen ink option it is drawn inside, in the canvas color.
- Disabled option: skipped by the arrow keys.
- Read-only: keeps its choice and shows no hover wash.
- Never disable the chosen option of a control the reader can still change. React Aria gives the tab stop only to the chosen option and takes it from a disabled one, so Tab skips the control.
- Missing name: the control does not compile. TypeScript either names only `aria-labelledby` or says the props are not assignable. Both mean the control has no accessible name.
