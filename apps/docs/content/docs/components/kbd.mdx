## Examples

Use one Kbd per key, so a shortcut has as many as it has keys. A key is as wide as its label, and tabular figures only keep a changing number steady. For a chord, HTML nests the keys in an outer `kbd`. A Kbd inside a Kbd draws as one chip, slightly taller than a lone key. A plain `kbd` inside it falls back to the browser's monospace face.

## Usage

A static `kbd` element with no React Aria, so it works in a server component without `'use client'`.

```tsx
import { Kbd } from '@snapshot-ui/react';

export function SearchHint() {
  return (
    <p>
      Press <Kbd>&#8984;</Kbd> <Kbd>K</Kbd> to search.
    </p>
  );
}
```

## Accessibility

A Kbd is read aloud like any text. When something nearby already names the shortcut, such as a button whose label says it, pass `aria-hidden` so it is not announced twice.
