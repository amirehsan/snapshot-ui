## Groups and items

A float rail 16px inside the screen edges, with the brand at the top, a search action, labelled groups of links, and an account row ruled off at the bottom. Put it inside an [App shell](/docs/components/app-shell), which owns its collapsed and drawer states.

- `SidebarGroup`: names its list with its label, a small uppercase line with a dot.
- `SidebarItem`: a link with an icon, a label and an optional count at the end.
- Current page: shown as an ink pill, and its group's dot lights up.

## Collapsed

Collapsed, the rail is a 72px column of icons. Each name shows as a tooltip on hover and keyboard focus. A count becomes a dot on the icon's corner, with its number and words on the tooltip's second line. Every item stays a tab stop, and the labels are hidden from view, not removed, so no name changes.

## The drawer

Below 1024px the rail is hidden. `SidebarTrigger`, an outline menu button for the page header, opens the same rail as a drawer from the start edge. The drawer always shows the labels and opens with focus on the current page. Pressing any item closes it, including the current one. This example opens the real drawer from a button, at any width.

## The current page

The library cannot see the router, so the app marks the current page. Read `usePathname()` in a client component and pass `isCurrent` to the item and its group. There is no built-in prefix match: whether `/budgets/2026` makes Budgets current is the app's rule.

```tsx
'use client';

import { SidebarGroup, SidebarItem } from '@snapshot-ui/react';
import { ChartColumn, PiggyBank } from 'lucide-react';
import { usePathname } from 'next/navigation';

export function InsightsGroup() {
  const pathname = usePathname();
  return (
    <SidebarGroup label="Insights" isCurrent={['/reports', '/budgets'].includes(pathname)}>
      <SidebarItem href="/reports" icon={<ChartColumn />} isCurrent={pathname === '/reports'}>
        Reports
      </SidebarItem>
      <SidebarItem href="/budgets" icon={<PiggyBank />} isCurrent={pathname === '/budgets'}>
        Budgets
      </SidebarItem>
    </SidebarGroup>
  );
}
```

## Slots

Each slot renders only when given.

- `brand`: a `SidebarBrand`, the mark and name as a link home. Collapsed, it keeps the mark, with the name as a tooltip.
- `search`: a `SidebarSearch`, a pill that opens the app's search in `onPress`. Collapsed, it keeps its icon, with the name as a tooltip.
- `footer`: anything, such as the signed-in account. Collapsed, it is centered. Read `useSidebar().isCollapsed` to show the account as an avatar alone.

While the drawer is open, the slots render twice, once in the rail and once in the drawer. Generate any id inside a slot with `useId`, never a fixed string, and read `useSidebar().inDrawer` to tell the copies apart. The same applies to `SidebarGroup`: an `id` you pass is repeated in the drawer copy, so leave the id to the library.

</Section>

## Usage

Sidebar and its parts are client components, and a server component can render them. Put the `Sidebar` in the shell's `sidebar` slot and a `SidebarTrigger` in its header.

- Search shortcut: `shortcut` takes keys separated by spaces, such as `"Mod K"`, shown as a key chip. After the page loads, `Mod` becomes Cmd on Apple platforms and Ctrl elsewhere. The server's HTML says Mod.
- Search name: the chip is part of the button's name in both states, such as "Search or jump to, Ctrl K".
- Counts: an item's `count` comes with its `countLabel`, so the item reads "Transactions, 12 to review".
- Links: items and the brand are React Aria links. `href` works before any script runs, a `RouterProvider` routes every press as [Routing](/docs/routing) shows, and `render` draws a router's own link for one item.

</Section>

## Accessibility

The rail is a `<nav>` named by its `aria-label`. Each group's list is named by the group's label, which is a paragraph, not a heading. The current page has `aria-current="page"`. Tab walks the rail in order, with no arrow keys to learn.

- Names never depend on state: a collapsed label stays in the name, and a count's words are always in it.
- The collapse button names what it will do and says whether the rail is expanded.
- The drawer opens with focus on the current page, keeps Tab inside, hides the page behind it, and returns focus to the menu button when it closes.
