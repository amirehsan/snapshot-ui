## Basic

Pass a label, and a hint if the label cannot say it all. The whole row is the target, so a press on the label flips the switch as well as a press on the track.

## States

On is an ink track with a canvas thumb. Off is the control boundary color with a raised thumb. A disabled switch is recessed, and one that is on is filled where one that is off is hollow, so the two never look alike. A read-only switch looks like an enabled one and cannot be changed.

## Unsaved changes

Pass `isChanged` while the setting differs from the saved one. A clay chip shows beside the label and a light signal orange ring goes around the track, and a screen reader reads the chip with the switch. Flip a switch below to see them.

## Usage

Every value works controlled and uncontrolled, and a switch with a `name` submits in a plain form. It sends its `value`, or `on` when it has none, only while it is on, as a checkbox does. `onChange` receives a boolean. A switch with no visible label needs an `aria-label`.

<Code code={`import { useState } from 'react';
import { Switch } from '@snapshot-ui/react';

export function DigestSetting({ saved }: { saved: boolean }) {
  const [isOn, setOn] = useState(saved);
  return (
    <Switch
      name="digest"
      value="weekly"
      description="Every Tuesday morning."
      isSelected={isOn}
      onChange={setOn}
      isChanged={isOn !== saved}
    >
      Weekly digest
    </Switch>
  );
}`} />

A switch is for a setting that takes effect as soon as it is flipped. It has no required or invalid state, so for a choice that a form confirms later, such as agreeing to terms, use a checkbox.

## Accessibility

A native checkbox with the `switch` role, so a screen reader says the label and then on or off. The track and the thumb are decoration. The label names the switch, the hint and the Changed chip describe it, and a press anywhere on the row flips it. The row is 40px tall to hit, though the track is drawn 30px.

<Keys rows={[['Space', 'Turns the switch on or off.'], ['Tab', 'Moves focus to the switch. The 2px ring sits outside the track.']]} />

Motion is a 160ms slide of the thumb and a fade of the track, and both stop under reduced motion.
