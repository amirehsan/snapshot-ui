## States

- On: an ink track with a canvas thumb.
- Off: the control boundary color with a raised thumb.
- Disabled: recessed, filled when on and hollow when off, so the two never look alike. The label is taupe, as on a disabled checkbox or radio.
- Read-only: looks enabled but cannot be changed.

## Unsaved changes

## Usage

A switch works controlled or uncontrolled, and `onChange` receives a boolean. With a `name`, it submits in a plain form. Like a checkbox, it sends its `value`, or `on` by default, only while it is on. The types require an accessible name: the switch's text, an `aria-label` or an `aria-labelledby`.

```tsx
import { useState } from 'react';
import { Switch } from '@snapshot-ui/react';

export function DigestSetting({ saved }: { saved: boolean }) {
  const [isOn, setOn] = useState(saved);
  return (
    <Switch
      name="digest"
      value="weekly"
      description="Every Tuesday morning."
      isSelected={isOn}
      onChange={setOn}
      isChanged={isOn !== saved}
    >
      Weekly digest
    </Switch>
  );
}
```

A switch has no required or invalid state. For a choice that a form confirms later, such as agreeing to terms, use a checkbox.

## Accessibility

A native checkbox with the `switch` role, so a screen reader says the label, then on or off. The label names it, and the hint and the Changed chip describe it. The track and thumb are decoration. The row is a 40px target, though the track is drawn 30px tall.

<Keys rows={[['Space', 'Turns the switch on or off.'], ['Tab', 'Moves focus to the switch. The 2px ring sits outside the track.']]} />

The thumb slides and the track fades over 160ms. Both stop under reduced motion.

A switch with no name does not compile. TypeScript's error either names only `aria-labelledby` or says the props are not assignable. Both mean the switch has no accessible name.
