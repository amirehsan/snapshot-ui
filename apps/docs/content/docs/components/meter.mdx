## Segments

Each segment is a share of `max`, stacked from the start of the bar: a solid fill for what is spent and ink stripes for what is held, committed but not gone. The rest of the track is the frame color. What passes `max` is clipped at the end, and a segment left with no room is not drawn.

## Pace and legend

`pace` places a marker where spending would be today if it kept pace, and its label is read with the meter as its description. `hasLegend` draws a row under the bar that names each segment with its value, then the marker.

## Over the limit

When the segments add up to more than `max`, both looks turn the warning color and the bar fills to its end. `valueLabel` must say "over" in words, such as "$340 of $300, $40 over", because color is never the only signal.

## On another surface

The cut between two segments and the ring around the pace marker are drawn in `--meter-surface`, which is Lifted by default, the card a meter sits on most. On the page itself, set `--meter-surface: var(--color-canvas)` on the meter or on any ancestor, and every meter inside follows.

```css
.budget-section {
  --meter-surface: var(--color-canvas);
}
```

</Section>

## Usage

Every figure is the app's formatted string: the library formats no number, so the server's HTML is final in any locale. The meter is static, so a server component renders it with no client JavaScript.

```tsx
import { Meter } from '@snapshot-ui/react';

<Meter
  label="Groceries"
  max={1200}
  segments={[
    { value: 820, look: 'fill', label: 'Spent', valueLabel: '$820.00' },
    { value: 200, look: 'hatched', label: 'Held', valueLabel: '$200.00' },
  ]}
  valueLabel="$1,020 of $1,200"
  pace={{ value: 900, label: "Where you'd be today: $900" }}
  hasLegend
/>;
```

## Accessibility

The bar is a `role="meter"` from 0 to `max`, named by the label or by `aria-label`, its value read as the app's `valueLabel` and never as a percentage, and its pace read as its description. The value text above the bar is hidden, since the meter reads it. The legend is a plain list outside the meter, because a meter's children are presentational. It takes no focus and has no keys.
