## Basic

The label sits beside the box and the whole row is the target, so a press on the text, the gap or the box toggles it. A hint goes under the label's text.

## States

Checked is an ink fill with a canvas mark, drawn with a mask so it reads in both themes. Indeterminate is a canvas bar. Invalid turns only the edge to the error color, so a checked box that is invalid still reads as checked. A disabled box is recessed with a taupe label, and a read-only box looks like an enabled one and cannot be pressed.

## Group

A group names several checkboxes and holds their values as one array. Vertical is the default. Horizontal lays the rows out side by side and wraps them when the row is full. The first group is controlled, and its selection differs from the saved one, so `isChanged` shows the clay chip beside the label. The boxes keep their edges: the chip marks the field, not each box.

## Select all

A parent checkbox is indeterminate while only some of its children are checked. Pass `isIndeterminate` and `isSelected` from the children's state, and it follows. Pressing an indeterminate checkbox reports `true`, which here checks every child.

## Validation

Set `isRequired` on a checkbox, or on a group where one checked box is enough, and the browser's own checks run when the form is submitted. The error line then shows the message, and every box in an invalid group turns its edge to the error color. A `validate` function works too.

## Usage

Every value works controlled and uncontrolled. A checked checkbox with a `name` submits its `value`, or "on", and an unchecked one is left out of the form. A group submits one entry per checked box, all under the group's `name`.

<Code code={`import { useState } from 'react';
import { Checkbox, CheckboxGroup } from '@snapshot-ui/react';

export function Preferences() {
  const [channels, setChannels] = useState(['email']);
  return (
    <form>
      <CheckboxGroup label="Notify me by" name="channels" value={channels} onChange={setChannels}>
        <Checkbox value="email">Email</Checkbox>
        <Checkbox value="sms">Text message</Checkbox>
      </CheckboxGroup>
      <Checkbox name="remember" defaultSelected>
        Remember me
      </Checkbox>
    </form>
  );
}`} />

</Section>

## Accessibility

A native checkbox input inside its label, with React Aria handling the wiring. The mixed state is exposed as mixed. A group is a `group` named by its label, and its hint and error line describe every checkbox in it. A screen reader reads the Changed chip with the group, after the hint, while the group is changed and valid. An invalid group reads its error line alone.

<Keys rows={[['Tab', 'Moves to the next checkbox. Each one is its own stop, in a group too.'], ['Space', 'Toggles the focused checkbox.'], ['Arrow keys', 'Do nothing. Only a radio group moves between its choices with them.']]} />

The row is 40px tall at the least, and the box is drawn at 20px inside it. In Windows high contrast the box takes the system colors, so the mark never disappears.
