## Basic

The label sits beside the box, and a press anywhere on the row toggles it. A hint goes under the label's text.

<Section>

## States

- Checked: an ink fill with a canvas mark, drawn with a mask so it reads in both themes.
- Indeterminate: a canvas bar.
- Invalid: only the edge turns to the error color, so an invalid checked box still reads as checked.
- Disabled: recessed, with a taupe label.
- Read-only: looks enabled but cannot be pressed.
- Changed: a clay chip beside the label and nothing else, read with the checkbox.

Invalid outranks changed, so the chip gives way to the error line. A checkbox with no visible label shows no chip. Inside a group, a checkbox ignores `isChanged`; the group's own chip covers it.

## Group

A group names several checkboxes and holds their values as one array. It is vertical by default. `orientation="horizontal"` lays the rows side by side and wraps them.

The first group is controlled and starts at its saved selection. Toggle a box and `isChanged` shows the clay chip beside the label, until the selection matches the saved one again. The chip marks the field, so the boxes keep their edges.

<Preview name="checkbox-group" />

A form reset returns a group to its `defaultValue`. A reset that only checks boxes, or unchecks a single box, works. Two cases fail because of React Aria:

- A reset that unchecks more than one box leaves all but the last of them checked.
- A reset that checks a box and unchecks one further down the group loses the checked box.

</Section>

## Select all

A parent checkbox is indeterminate while only some of its children are checked. Derive `isIndeterminate` and `isSelected` from the children's state. Pressing an indeterminate checkbox reports `true`, which here checks every child.

## Validation

Set `isRequired` on a checkbox, or on a group where one checked box is enough, and the browser checks it on submit. The error line shows the message, and every box in an invalid group gets the error edge. A `validate` function works too. A group shows only its own error line, so an `errorMessage` on a checkbox inside it is not shown.

## Usage

Every value works controlled and uncontrolled. A checked checkbox with a `name` submits its `value`, or "on". An unchecked one is left out of the form. A group submits one entry per checked box under the group's `name`.

```tsx
import { useState } from 'react';
import { Checkbox, CheckboxGroup } from '@snapshot-ui/react';

export function Preferences() {
  const [channels, setChannels] = useState(['email']);
  return (
    <form>
      <CheckboxGroup label="Notify me by" name="channels" value={channels} onChange={setChannels}>
        <Checkbox value="email">Email</Checkbox>
        <Checkbox value="sms">Text message</Checkbox>
      </CheckboxGroup>
      <Checkbox name="remember" defaultSelected>
        Remember me
      </Checkbox>
    </form>
  );
}
```

The types require a name: text, `aria-label` or `aria-labelledby` for a checkbox, and `label`, `aria-label` or `aria-labelledby` for a group.

## Accessibility

A native checkbox input inside its label, wired by React Aria. The indeterminate state is exposed as mixed. A group is a `group` named by its label, and its hint and error line describe every checkbox in it.

- A group's Changed chip is read with the group.
- A standalone checkbox's chip is read as part of its description, after the hint, while changed and valid. It sits beside the row, so it is not part of the name and pressing it does not toggle the box.
- An invalid group or checkbox reads its error line alone.

<Keys rows={[['Tab', 'Moves to the next checkbox. Each one is its own stop, in a group too.'], ['Space', 'Toggles the focused checkbox.'], ['Arrow keys', 'Do nothing. Only a radio group moves between its choices with them.']]} />

The row is at least 40px tall, with a 20px box. A checkbox with no text, named by `aria-label`, keeps a 40px square target that overhangs the box by 10px on each side, so leave 10px beside a scroll edge. In Windows high contrast the box takes the system colors, so the mark never disappears.

A checkbox or group with no name does not compile. TypeScript's error either names only `aria-labelledby` or says the props are not assignable. Both mean it has no accessible name.
