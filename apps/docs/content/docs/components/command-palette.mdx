## Basic

A dialog with a search field over a list. Type to filter, use the arrows to move, and press Enter to open the active item.

- Filtering: an item matches when every word you type appears in its label, second line or keywords, ignoring case and accents. "cafe lumiere" finds Café Lumière.
- Items: each can have an icon, a second line, a preformatted value at its end, and a key hint.
- Sections: items with a `section` are grouped under it, after the items without one.
- Recent: with `storageKey`, the last five chosen items are listed first while the field is empty.

Cmd or Ctrl+K opens and closes the palette, and `shortcut` changes the key. It also works on layouts that type another script, such as Persian or Russian. This site's search already uses Cmd or Ctrl+K, so the example below uses Cmd or Ctrl+J.

## Async results

To search on your server, pass `filter={null}`, and the palette shows `items` as given. Control the field with `inputValue` and `onInputChange`, then fetch, rank and cap the results yourself. Set `isLoading` while a request runs: the field shows a spinner, and the list keeps its results until new ones arrive. Here a 400ms timer stands in for the request.

## Usage

Open the palette from your own button with `isOpen` and `onOpenChange`, and show the key beside it with a `Kbd`. Navigate in `onAction`: it runs after the palette has closed and focus has returned, so nothing undoes your navigation. The palette has no `href` or routing of its own.

```tsx
'use client';

import { CommandPalette } from '@snapshot-ui/react';
import { useRouter } from 'next/navigation';
import { PAGES } from './pages';

interface AppSearchProps {
  isOpen: boolean;
  onOpenChange: (isOpen: boolean) => void;
}

export function AppSearch({ isOpen, onOpenChange }: AppSearchProps) {
  const router = useRouter();
  return (
    <CommandPalette
      label="Search"
      items={PAGES}
      isOpen={isOpen}
      onOpenChange={onOpenChange}
      storageKey="app-search"
      onAction={(item) => {
        router.push(`/${String(item.id)}`);
      }}
    />
  );
}
```

The shortcut listens on the whole page while the palette is mounted. It skips keys another handler has already taken and keys typed while composing text, and it is off while a Dialog, ConfirmDialog, Drawer or Sheet is open. For a modal of your own, call `preventDefault()` on the shortcut's keydown inside it. `shortcut={false}` turns the shortcut off.

- `labels` replaces the palette's own words: the placeholder (the `label` by default), the empty line, the spinner's name, the Recent heading, the status line and the key hints.
- To keep recent items yourself, such as on your server, pass `recentIds` (newest first) and `onRecentChange`. The palette then stores nothing. Without `recentIds`, `onRecentChange` still receives each stored list, with every id as a string.
- A remembered id that is no longer in `items` is dropped.
- Values in `end` are shown as given, so format them first. On a right-to-left page, wrap a signed amount in an element with `dir="ltr"` to keep its sign in front.

## Accessibility

The dialog and its field are both named by `label`. Focus stays in the field while the arrows move a virtual active row, which a screen reader announces and which is drawn as the ink fill. Once typing pauses, a status line announces the number of results. Escape closes the palette and returns focus.

<Keys rows={[['Mod K', 'Opens and closes the palette (Mod is Cmd or Ctrl).'], ['Down Up', 'Move the active row, wrapping.'], ['Home End', 'Jump to the first or last row.'], ['PageUp PageDown', 'Move the active row by a page of the list.'], ['Enter', 'Opens the active item.'], ['Escape', 'Closes the palette.'], ['Tab', 'Stays in the dialog.']]} />
