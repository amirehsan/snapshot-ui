## Basic

A `Calendar` chooses one day. It has no visible label, so name it with `aria-label` or `aria-labelledby`. Its value is an ISO date, `'2026-09-14'`, in `value` or `defaultValue` and out of `onChange`. A server component can pass it straight from a URL. Pass `today` to mark that day with a ring and a bold number, and to open on its month when there is no value.

## Range

A `RangeCalendar` chooses a range in two presses. The first press anchors it, and the days under the pointer or focus preview the range until the second. For a one-day range, press the same day twice. The value is `{ start, end }`, two ISO dates, and `onChange` fires once the range is complete.

A half-chosen range is dropped when focus leaves the calendar, or when a press lands outside it or on anything in it that is not a button, such as the month heading. An unfinished range never reaches the URL.

`presets` adds a row of the app's own ranges above the grid. The library computes no ranges: compute "This month" from the app's today, ideally on the server.

- A press sets the range and moves the view to its start.
- A preset shows pressed while the value equals its range.
- A preset is disabled when it falls outside `minValue` or `maxValue`, or holds a day `isDateUnavailable` rejects.

## Unavailable days

- `minValue` and `maxValue`: ISO dates. Days outside them are taupe and cannot be chosen.
- `isDateUnavailable`: receives each day as an ISO date and returns true for a day that cannot be chosen, such as a closed day or a weekend. Those days are taupe and struck through.

A function cannot cross from a server component, so the example is a client file.

## Calendars and digits

The locale, set through `I18nProvider`, chooses the calendar and its digits:

- `fa-IR`: the Persian calendar (Shahrivar 1405) in Persian digits, with weeks from Saturday.
- `fa-IR-u-ca-gregory`: the Gregorian calendar in Persian digits.
- `fa-IR-u-nu-latn`: the Persian calendar in Latin digits.

Values stay Gregorian ISO dates whatever the calendar shown, so a URL means the same day on every page.

<Preview name="calendar-persian" />

React Aria's calendar brings every calendar system. To ship only Gregorian and Persian, pass a `createCalendar` that returns one of the two, from `@internationalized/date`. Install it at React Aria's own range (`^3.12.4`) so there is one copy:

```tsx
'use client';

import { GregorianCalendar, PersianCalendar, type CalendarIdentifier } from '@internationalized/date';

export const createCalendar = (identifier: CalendarIdentifier) =>
  identifier === 'persian' ? new PersianCalendar() : new GregorianCalendar();
```

This narrows only a calendar's bundle. Date fields always build their own calendars, so a page with a date range picker ships every system anyway.

</Section>

## Today

Pass `today` as an ISO date in the app's time zone. Near midnight the device can be on a different day, and a "This month" preset computed on the server would disagree with a mark from the device. Without `today`, the calendar marks the device's today once the page has loaded. React Aria's spoken "Today" always follows the device.

</Section>

<Section>

## Usage

Keep a date in a search parameter as its ISO string, `?from=2026-09-01&to=2026-09-30`, and pass it as `value`. A string that does not parse, or a range that ends before it starts, reads as no value and warns in the console. A hand-edited URL never throws.

- A calendar always holds six weeks, so changing months never moves the layout.
- Before hydration, an inline calendar draws its face: the header, weekday row, six weeks of days and a range calendar's presets, with no dates. The face is inert and hidden from screen readers.
- React Aria's calendar mounts in the next render, since its month, weekdays, days and today come from `Intl` and the device's zone. Nothing moves when it arrives.
- A calendar in a popover or a sheet is only drawn in the browser.

</Section>

## Accessibility

The calendar is an `application` named by its `aria-label` and the visible month, holding a `grid` of days. Each day is named with its full date and described as today, selected or unavailable, in React Aria's strings, which have no Persian. React Aria announces month changes and the chosen range.

- The month buttons are named "Previous month" and "Next month", or by `labels`.
- The presets are a group of toggles named "Presets", each pressed while the value equals its range.
- Days are 40px where there is room, and at least 36px in a popover, or in the sheet on a 320px screen.
- Inline, days shrink with their container but never below the 24px target minimum, so the calendar is at least 168px wide.
