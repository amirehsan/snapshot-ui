## Basic

A plain number takes a label. `hasStepper` adds minus and plus buttons at the end.

- Arrows and Page Up or Page Down step by `step` (1 by default). They snap to the step first, so an empty field starts at the lower bound.
- Enter commits and formats the value.
- Home and End move the caret, as in any text box, and still reach your `onKeyDown`.
- `formatOptions` takes `Intl` options for a decimal, a percent or a unit. Compact notation is not supported, since only `Intl` knows its rounding.

Each stepper's hit area is 40px tall, even when compact density draws it at 24px, and the two split the 2px between them.

## Money

Pass `money={{ symbol: '$' }}` and the value becomes an integer count of minor units: `123450` is 1,234.50. A URL and a database hold it exactly, and sums never drift. The readout under the example shows the value the field holds.

- `fractionDigits`: 2 by default, from 0 for a currency with no minor unit up to 3.
- Precision: exact up to `2 ** 52 / 10 ** fractionDigits` minor units, about 45 trillion cents. Past that, the field warns in the console.
- Symbol: drawn beside the figure in slate and never typed, so the caret never lands in it. A pasted "$1,234.50" reads as the amount, and your `onPaste` still runs.
- No currency style: `Intl`'s would put the caret inside the symbol and choose its side during render.
- No steppers and no wheel: an amount is typed, and a typed 12.50 is never snapped to a step.

## Negatives

Without `allowsNegative`, the lower bound is 0. With it, a sign button sits at the field's start, because neither iPhone nor Android decimal keyboards have a minus key.

- The button is a toggle, pressed while the value is under zero. It negates the value, kept within `minValue` and `maxValue`.
- On an empty field or at zero, it types a minus and focuses the field, so the field never shows "-0.00" and `onChange` never receives -0.
- A minus typed on a hardware keyboard works too, and the button follows it.
- A negative amount is ink, with its sign. Never red, since nothing failed.
- On a disabled or read-only field the button is disabled. A negative value then shows it pressed but recessed: a light ink fill with a taupe minus.

## Right to left

Set the symbol's side with `symbolPosition`, in the field's direction. On a Persian page, both "تومان" and "$" go at the end, which Persian writing puts left of the digits. The figure stays left to right on every page, so its sign stays in front. React Aria writes it in the locale's digits after the page loads.

## Focus leaving while React draws

React Aria commits the typed text when the field loses focus, inside `flushSync`. When focus leaves while React draws, as when a Save disables the form's fields or an app moves focus from a layout effect, React used to log "flushSync was called from inside a lifecycle method". The field now defers React Aria's commit by one microtask, so nothing is logged. The value still commits before the next click and before a submit, and a corrected value is still announced.

- Your `onBlur` and `onFocusChange(false)` run one microtask after the blur.
- A script that calls `requestSubmit()` in the same task as a blur reads the form before the commit. Submit from the press instead, or wait a microtask.

</Section>

## Usage

Keep an amount filter in the URL as minor units, `?min=2000`. A client component reads it with `Number()`, treating an absent or malformed value as `null`, and passes it as `value`. It writes the URL in `onChange`, which fires when the value commits (on blur, Enter, a step or the sign button), never on a keystroke. With the Next App Router:

```tsx
'use client';

import { useState } from 'react';
import { usePathname, useRouter, useSearchParams } from 'next/navigation';
import { NumberField } from '@snapshot-ui/react';

const minorOf = (raw: string | null): number | null =>
  raw === null || raw === '' || !Number.isSafeInteger(Number(raw)) ? null : Number(raw);

export function MinimumAmount() {
  const router = useRouter();
  const pathname = usePathname();
  const searchParams = useSearchParams();
  const min = minorOf(searchParams.get('min'));
  const [value, setValue] = useState(min);
  const [seen, setSeen] = useState(min);

  // The URL changed under the field, by Back, Forward or a link: show its amount.
  if (min !== seen) {
    setSeen(min);
    setValue(min);
  }

  return (
    <NumberField
      label="Minimum amount"
      money={{ symbol: '$' }}
      value={value}
      onChange={(next) => {
        setValue(next);
        setSeen(next);
        const params = new URLSearchParams(searchParams);
        if (next === null) params.delete('min');
        else params.set('min', String(next));
        const query = params.toString();
        router.replace(query ? `${pathname}?${query}` : pathname, { scroll: false });
      }}
    />
  );
}
```

- On a statically rendered route, render it inside `<Suspense>` with an empty field as the fallback.
- In a form, `name` sends minor units in money mode and the number otherwise.
- Before hydration, the field shows the plain figure, "1234.50", in ASCII digits with no grouping. React Aria's formatted text, "1,234.50" or "۱٬۲۳۴٫۵۰", follows in the next render. The server's HTML is the same in every locale and time zone, and nothing moves.

## Accessibility

The field is a `textbox` (React Aria removes the spin button role), named by its label and described by its hint, symbol and Changed chip: "Amount, 1,234.50, $". React Aria announces a committed value in its own strings.

- Sign button: a toggle with `aria-pressed`, named "Negative" or `labels.negative`. It is its own tab stop.
- Steppers: named "Increase" and "Decrease" plus the field's label. They are out of the tab order, since the arrows do the same.
