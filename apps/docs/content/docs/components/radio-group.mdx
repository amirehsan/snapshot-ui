## States

- Changed: a clay chip beside the label is the only cue, since a choice has no control edge to recolor. A group with no visible `label` shows no chip.
- Invalid: every row gets the error edge, and an error line shows. Invalid outranks changed, so the chip hides.
- Disabled: the group is recessed and keeps the check on its choice. One option can be disabled on its own, with its label in taupe.

## Validation

Set `isRequired` or a `validate` function, and the browser's checks run on submit. The error line shows the message, and choosing an option clears it. The first failed submit moves focus to the group.

## Usage

Every value works controlled and uncontrolled. A group with a `name` submits the chosen `value` in a plain form. `onChange` receives the value as a string.

```tsx
import { useState } from 'react';
import { Radio, RadioGroup } from '@snapshot-ui/react';

export function Frequency({ saved }: { saved: string }) {
  const [value, setValue] = useState<string | null>(saved);
  return (
    <RadioGroup
      label="Newsletter frequency"
      name="frequency"
      value={value}
      onChange={setValue}
      isChanged={value !== saved}
    >
      <Radio value="weekly" description="Every Tuesday morning.">
        Weekly
      </Radio>
      <Radio value="monthly">Monthly</Radio>
      <Radio value="never">Never</Radio>
    </RadioGroup>
  );
}
```

The types require a name. A group takes a `label`, an `aria-label` or an `aria-labelledby`. A `Radio` takes its text, an `aria-label` or an `aria-labelledby`.

For an on or off setting, use a switch. For a choice that changes the view in place, such as a mode, use a segmented control.

## Accessibility

A group of native radio inputs, named by the label. The hint, the error line and, while it shows, the Changed chip describe it. The group is one tab stop, and the arrow keys move the choice. The dot and the check are decoration, so an option's name is its label text.

<Keys rows={[['Tab', 'Moves focus into the group, to the chosen option or the first one. The 2px ring sits outside an unchosen row and inside the ink of the chosen one.'], ['Down Right', 'Moves to the next option and chooses it.'], ['Up Left', 'Moves to the previous option and chooses it.'], ['Space', 'Chooses the focused option.']]} />

- The arrow keys skip disabled options.
- A read-only group keeps its choice and has no hover wash.
- Do not disable the chosen option of a group the reader can still change. Only the chosen radio gets the tab stop, and a disabled one loses it, so Tab skips the group.

A group or option with no name does not compile. TypeScript's message names only `aria-labelledby` or says the props are not assignable. Either one means a missing accessible name.
