## Usage

Give it an `href`. For a link that opens a new tab, pass `target` and `rel` as you would to an anchor.

```tsx
import { Link } from '@snapshot-ui/react';

export function Footnote() {
  return (
    <p>
      Built on{' '}
      <Link href="https://react-aria.adobe.com" target="_blank">
        React Aria
      </Link>
      .
    </p>
  );
}
```

Every link follows the app's router through one `RouterProvider`; see [Routing](/docs/routing).

## Accessibility

A native anchor, with React Aria handling press across mouse, touch and keyboard. A disabled link is announced as disabled and cannot be followed.

Link sets no `rel` of its own. Browsers already treat `target="_blank"` as `noopener`, so add `rel="noreferrer"` only to hide where the visitor came from. A link that opens a new tab should say so in or beside its text, for people who cannot see the tab bar.
