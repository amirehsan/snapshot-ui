## One series

A line chart draws a figure across a run of days: a 2px ink line in an svg stretched to the plot, gridlines at the `yTicks` with their labels above them, and the first, middle and last day under it. Focus the plot, or point at it, and a readout shows the day and its value.

## Compared with last month

A second series is context, not a second story: it is drawn thinner and in slate, under the first, and a legend names both. The readout and the table name each series beside its value, so the two are never told apart by color alone.

## Gaps

A day with no value, such as one still to come, is `null`. The line breaks there, the keys and the pointer skip it, the readout leaves out a series with no value, and the table's cell is empty. `hasArea` fills under the first series with a 10% ink wash, which breaks with the line.

<Section>

## The table

Every chart has a toggle under it, Show as table, that swaps the plot for a table of the same strings: a row per day and a column per series. It is for anyone who would rather read the numbers, not only for a screen reader, so it is visible when chosen. With scripts off the toggle cannot work, so the table is shown under the plot with a note that says so.

The table is named as the chart is: by a caption that repeats the `aria-label`, or, when the chart is named by `aria-labelledby`, by the same heading and no caption.

</Section>

<Section>

## Right to left

Time follows the page's direction, so under `dir="rtl"` the newest day is at the left, and Left moves to newer days. The direction comes from the nearest `dir="ltr"` or `dir="rtl"` attribute, which the svg, the marks over it and the keys all read, so they always agree; `dir="auto"` is looked past. The figures inside the labels are the app's strings.

## Usage

```bash
pnpm add @snapshot-ui/charts @snapshot-ui/core
```

It needs the same 0.x minor of `@snapshot-ui/core` (0.5 for charts 0.1.2), whose `styles.css` draws it. Every label and value is your formatted string: `valueLabel` says a point and `value` only places it, so a currency, a compact figure or Persian digits are yours, and the server's HTML is final. Pass `yTicks` for gridlines with labels; without them the chart draws only its baseline and relies on the readout and the table. Pass the same `yDomain` to charts read side by side, so their scales match. In another language, pass `labels` with all four of the strings the chart writes itself: the toggle's two, the note shown with scripts off, and the plot's role description, which a screen reader says in place of "chart".

The svg, the axis labels, the legend and the table render on the server; the client adds the keys, the pointer and the readout. A server component can render it and pass it plain data.

```tsx
import { LineChart } from '@snapshot-ui/charts';

<LineChart
  aria-label="هزینه‌های مهر"
  series={[
    { label: 'این ماه', points: [{ value: 42.1, valueLabel: '۴۲٫۱۰ دلار' }, null] },
    { label: 'ماه گذشته', points: [{ value: 35, valueLabel: '۳۵ دلار' }, { value: 41.2, valueLabel: '۴۱٫۲۰ دلار' }] },
  ]}
  xLabels={['۱ مهر', '۲ مهر']}
  yTicks={[
    { value: 0, label: '۰ دلار' },
    { value: 50, label: '۵۰ دلار' },
  ]}
  labels={{
    showTable: 'نمایش جدول',
    showChart: 'نمایش نمودار',
    noScript: 'اسکریپت‌ها خاموش‌اند، پس داده‌های نمودار در جدول زیر است.',
    roleDescription: 'نمودار',
  }}
/>;
```

## Accessibility

The chart is a `figure` named by its `aria-label` or `aria-labelledby`, which the types require. The plot is one tab stop for the whole chart, a group with the role description "chart" (`labels.roleDescription`) named as the figure is, so thirty-one days are never thirty-one tab stops. It becomes a tab stop once scripts run, since its keys need them. The arrow keys move a readout and a crosshair through the days with data; the readout sits above the day's dots, or below them when they are near the top, so it never covers the point it describes. A key with Alt, Control or Meta is left to the browser. A screen reader hears the day and each series with its value once the keys rest for 150ms, so a held key is heard only where it stops; each part is announced on its own, with no punctuation of the library's between your words. The pointer snaps to the nearest day across the whole column, never only on the line. The table is the full alternative. In forced colors the first line is drawn in the reader's text color, the second and the gridlines in GrayText, and the crosshair and dots in Highlight.
