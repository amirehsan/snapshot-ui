## What it is

Components that read calm: cream surfaces, one typeface, corners from one scale and colors that carry meaning.

Every interactive component is built on [React Aria](https://react-aria.adobe.com), so keyboard use, focus and screen readers work the way the WAI-ARIA patterns describe. The styling is plain CSS in its own package, so the same look will serve a plain HTML version later.

</Section>

<Section>

## Packages

There are three packages. `@snapshot-ui/core` and `@snapshot-ui/react` are released together with matching versions. `@snapshot-ui/charts` is versioned on its own.

- `@snapshot-ui/core` holds the design tokens, the Tailwind v4 theme and every component's CSS. It has no JavaScript.
- `@snapshot-ui/react` holds the React components. It ships no CSS of its own.
- `@snapshot-ui/charts` holds the charts, drawn on the server in SVG. Its CSS is in `@snapshot-ui/core`.

</Section>

## Status

The library is at 0.x and grows phase by phase.

Phase 1 is the foundation and the form basics. Choice controls and overlays, specialised inputs, lists and data, and the app shell follow, then charts and the HTML version. Breaking changes are possible before 1.0 and are always listed in the changelog.

Some components arrived early:

- Charts, for a home page's figures: a line chart and a sparkline.
- List page basics, for a transactions page: a search field, a select, a combo box, a multi-select, tabs and pagination.
- List page filters, for the same page: a number field with a money mode, a calendar, a date range picker, a filter chip and a filter bar.
- The list itself, for the same page: a data table with a list face for phones, an empty state, a skeleton and a side panel.
- A documents flow, for receipts and statements: a file drop zone, an upload tray, a progress bar, a date picker, a save bar, a page header and breadcrumbs.
- An account's pages: a description list for its details, actions in a card's header, a gauge for a score or a limit, and a month grid for which statements you have.
